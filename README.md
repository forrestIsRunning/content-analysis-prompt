# 内容分析与项目知识构建 Prompt

这是一个用于分析 YouTube、Bilibili、抖音、播客、网页课程、长文和文章等在线内容的中文 Prompt。

目标是把外部信息转化为结构清晰、可长期复用、能直接服务于具体 Project 的知识笔记。

## 使用方式

将 [prompt.md](prompt.md) 中的内容作为系统提示词或自定义 GPT/Agent 的核心指令。

使用时建议先告诉 Agent：

- 当前 Project 的背景、目标和痛点
- 你希望分析的链接
- 输出深度：默认分析、快速总结、深度分析

## 支持模式

- 默认分析：输出完整 8 节结构
- 快速总结：只输出「内容元数据与快速概览」和「核心 Takeaways」
- 深度分析：重点扩展「详细关键点与笔记」和「对 Project 的可行动洞见」

## 输出格式

Prompt 要求统一使用 Obsidian / Notion 友好的 Markdown，便于长期积累、搜索和横向对比。
