# Video Knowledge Builder Prompt

中文 | [English](#english)

## 中文

这是一个面向 YouTube、Bilibili、抖音、快手、Vimeo、课程录像和播客视频的双语 Prompt，用于把视频内容转化为结构清晰、可长期复用、能直接服务 Project 的知识笔记。

它特别适合这些场景：

- 看完长视频后快速获得可执行总结
- 把视频内容沉淀到 Obsidian / Notion
- 将教程、访谈、课程、产品演示转化为项目洞见
- 对同一 Project 下的视频资料做统一格式归档

## 文件

- [prompt.zh.md](prompt.zh.md)：简体中文 Prompt
- [prompt.en.md](prompt.en.md)：English Prompt
- [description.zh.md](description.zh.md)：中文项目描述
- [description.en.md](description.en.md)：English project description

## 使用方式

将对应语言的 Prompt 放入系统提示词、自定义 GPT、Agent 或工作流中。

建议每次使用前补充：

- 当前 Project 的背景、目标和痛点
- 视频链接
- 输出深度：默认分析、快速总结、深度分析

## 输出模式

- 默认分析：输出完整 8 节结构
- 快速总结：只输出「内容元数据与快速概览」和「核心 Takeaways」
- 深度分析：重点扩展「详细关键点与笔记」和「对 Project 的可行动洞见」

## English

This repository provides a bilingual prompt for turning videos from YouTube, Bilibili, TikTok/Douyin, Kuaishou, Vimeo, course recordings, and video podcasts into reusable project knowledge notes.

It is designed for:

- Summarizing long videos into actionable notes
- Saving video insights into Obsidian / Notion
- Converting tutorials, interviews, lectures, and product demos into project decisions
- Keeping a consistent knowledge format across one project

## Files

- [prompt.zh.md](prompt.zh.md): Simplified Chinese prompt
- [prompt.en.md](prompt.en.md): English prompt
- [description.zh.md](description.zh.md): Chinese project description
- [description.en.md](description.en.md): English project description

## How to Use

Paste the prompt into a system prompt, custom GPT, agent, or workflow.

Before each analysis, provide:

- Project background, goals, and pain points
- Video link
- Desired depth: default analysis, quick summary, or deep analysis
