# Project Description

**Video Knowledge Builder Prompt** is a bilingual prompt set for turning videos from YouTube, Bilibili, TikTok/Douyin, Kuaishou, Vimeo, course recordings, and video podcasts into structured, reusable, project-ready knowledge notes.

Its goal is not only to summarize a video, but to answer:

- Why does this video matter to the current project?
- Which ideas, methods, tools, and examples should be saved?
- What concrete actions should be taken next?

The repository includes both Chinese and English versions for custom GPTs, agents, Obsidian/Notion workflows, and automated video analysis pipelines.
